HTML Is the Backbone


HTML provides the basic structure of web pages.It uses elements and tags to define content like headings, paragraphs,image and limks. Each element has a specific purpose, making web content semantic and organized.You should be familiar with elements like <div>, <span>, <nav>, <section>, and more.

CSS Adds Style


CSS controls the visual apperance of the webpage. Properties like 'color','background-color', 'font-family', and 'display' can change how the page looks.CSS can be applied in three ways: inline,external, and internal. In this tasks, we only use internal CSS written inside the tag of each page.

Positioning Elements


The 'position' property in CSS let us place elements exactly where we want comman values include: static, relative ,absolute ,fixed, and sticky. In this task,the navbar is fixed to the top, always visible as your scroll.
